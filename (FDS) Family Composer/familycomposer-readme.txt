*****************
*Family Composer*
*****************

Family Composer is a music creation game for the Famicom Disk System.  It was published by Tokyo Shoseki and developed by Musical Plan.  With this, you could make music, similar to Ikinari Musician.

The patch comes in two flavors...

Family Composer (English).ips
--English translation patch (IPS Format)
Family Composer (English).bps
--English translation patch (BPS Format)

This patch requires the ROM with the following hashes...

File/ROM SHA-1: E15A395393090B433CB2EDCB0CC3BF4D876A8E08
File/ROM CRC32: 1E451B9

Use either the IPS or the BPS patch to get the ROM with the following hashes. (Don't use both patches.)

File/ROM SHA-1: 1BBBBACC4D5DD820F8AAD5B5BED307EA788C080F
File/ROM CRC32: 842C34CE

What's done?

Translated title screen
Very little Japanese text translated to English
